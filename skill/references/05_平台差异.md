# 05 · 平台差异

## TikTok Shop（美区）

| 项 | 口径 |
|---|---|
| 时长 | 9–15 秒投流版；15–34 秒自然版 |
| 画幅 | 9:16，1080×1920 |
| 结构 | Hook 3–6s（必须产品相关）→ Key Message → CTA |
| CTA | 口播 + 屏幕文字；"点左下角小黄车" |
| 合规 | FTC 披露（#ad/#tiktokshop）、AI 标识、不得站外导流 |
| 素材量 | 一个品 3–5 条不同钩子，投流赛马 |

## TikTok Shop（东南亚：印尼/泰国/越南/马来）

| 项 | 口径 |
|---|---|
| 时长 | 9–15 秒，节奏更快 |
| 语言 | 当地语言字幕 + 简单英语 |
| 客单价 | 低，钩子更强调"价格/赠品/立刻" |
| 合规 | 当地广告法 + 平台 AI 标识 |
| 注意 | 宗教/文化敏感（服饰、食品） |

## 抖音 / 千川

| 项 | 口径 |
|---|---|
| 时长 | 15–30 秒；千川 15 秒为主 |
| 画幅 | 9:16 |
| 结构 | 前 3 秒完播率决定跑量；痛点前置 |
| CTA | "点小黄车""左下角"；直播间引流另说 |
| 合规 | 广告法禁词、医疗宣称、诱导互动 |
| 特点 | 素材衰减快，一个品需 5–10 条备选 |

## 视频号

- 更吃"熟人信任"，节奏稍慢，口播更口语
- 外链受限，转化靠私域/小程序

## 小红书

- 带货以"种草笔记 + 商品卡"为主
- 软广必须报备；正文不能留联系方式
- 画面审美要求高于其他平台

## 一个产品跨平台复用

```
主片 15 秒（共用骨架）
├── 美区版：英文口播 + #ad 披露 + AI 标识
├── 东南亚版：当地语言字幕 + 价格钩子
├── 抖音版：中文口播 + 广告法过词 + 小黄车
└── 小红书版：慢节奏 + 审美向 + 报备
```
