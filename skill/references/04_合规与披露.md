# 04 · 合规与披露

> 带货内容的风险不在创意，在**一句话说错就被下架/罚款**。以下为出词前必过项。

## 一、广告法禁词（国内）

**绝对化**：最、第一、顶级、极致、唯一、首个、国家级、王牌
**保证性**：保证、承诺、100%、永久、根治、彻底解决
**医疗类**：治疗、治愈、疗效、药效、修复（用于身体时）、消炎、杀菌（需资质）
**虚假对比**：全网最低、比某大牌好（指名道姓）

替换建议：
- 最好 → 很好 / 我用下来最顺手的（仍慎用"最"）
- 根治 → 改善 / 缓解
- 永久 → 长期 / 耐用
- 100% → 实测（附条件）

## 二、FTC / 平台披露（美区）

- 带货佣金 = 实质性关系 → **必须披露**（#ad、#tiktokshop、口头说明）
- 测评必须基于真实使用；不得虚构体验
- 前后对比必须真实、可复现，不得修图夸大
- 功效宣称需有证据；健康类尤其严格
- 平台要求：AI 生成内容标注（AI-generated）

## 三、AI 内容标识

- TikTok / 抖音 / 小红书均要求 AI 生成内容打标
- 数字人口播需在文案或画面标注"数字人/AI 生成"
- 未标注风险：限流、下架、账号处罚

## 四、平台特殊规则

| 平台 | 禁止 | 注意 |
|---|---|---|
| TikTok | 站外导流、虚假促销、医疗宣称 | 小黄车必须合规挂载 |
| 抖音 | 诱导互动、绝对化、医疗 | 千川素材需过审 |
| 小红书 | 留联系方式、软广不标 | 报备笔记 |
| 视频号 | 诱导分享 | 外链受限 |

## 五、出词前检查清单

- [ ] 无绝对化用语
- [ ] 无保证性承诺
- [ ] 无医疗/疗效表述
- [ ] 对比真实可复现
- [ ] 有披露语（如适用）
- [ ] 有 AI 标识（如适用）
- [ ] CTA 不诱导违规（不写"私信我拿链接"）

## 六、一句话原则

**只写能被这一条视频证明的话。** 证明不了的，删掉。
