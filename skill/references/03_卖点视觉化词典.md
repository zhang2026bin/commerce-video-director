# 03 · 卖点视觉化词典

> 原则：**观众看不见的卖点，等于没有卖点。**
> 用法：拿到卖点 → 查表 → 选一个可拍的画面 → 写进分镜。

## 材质类

| 卖点 | 画面 | 提示词关键词 |
|---|---|---|
| 柔软 | 手指按压回弹、贴脸 | 微距、按压缩放、回弹 |
| 厚实 | 双手撑开、光透过厚度 | 逆光、厚度对比、阴影 |
| 透气 | 蒸汽穿透布料 | 蒸汽、慢镜头、透光 |
| 防水 | 水珠滚落、纸巾不湿 | 水珠、荷叶效应、特写 |
| 耐磨 | 钢丝刷来回刷 | 摩擦、无痕、连续动作 |
| 真皮 | 纹理微距、按压褶皱 | 毛孔纹理、按压、光泽 |

## 功能类

| 卖点 | 画面 | 提示词关键词 |
|---|---|---|
| 吸水量 | 一杯水倒上，3 秒吸干 | 倒水、瞬吸、计时字幕 |
| 承重 | 挂重物（水桶/哑铃） | 悬挂、形变极小、稳定 |
| 容量 | 一件件塞进去直到满 | 连续放入、物品堆叠 |
| 速热 | 温度计数字上升 | 特写温度计、计时 |
| 静音 | 分贝仪对比 | 分贝数字、对比镜头 |
| 续航 | 计时器 + 使用场景 | 计时、连续使用 |

## 效果类

| 卖点 | 画面 | 提示词关键词 |
|---|---|---|
| 显瘦 | 同一人两件对比、侧身 | 同角度、侧身、对比分割 |
| 提亮 | 半边脸对比 | 同光线、前后分割 |
| 去污 | 脏面擦一半 | 中线分割、擦拭轨迹 |
| 收纳 | 收纳前后俯拍 | 俯拍、同机位、物品数量 |
| 蓬松 | 手抓头发回弹 | 慢动作、回弹、光泽 |

## 体验类

| 卖点 | 画面 | 提示词关键词 |
|---|---|---|
| 轻便 | 单手拎、塞小包 | 单手持、放入包内 |
| 好清洗 | 水冲即净 | 冲水、无残留 |
| 不勒 | 手指插入松紧带 | 拉伸、手指空间 |
| 好收纳 | 折叠成小方块 | 折叠、体积对比 |

## 信任类

| 卖点 | 画面 | 提示词关键词 |
|---|---|---|
| 质检 | 报告特写/盖章 | 文件特写、红章 |
| 销量 | 后台数据（打码） | 数字滚动、马赛克 |
| 复购 | 多件同款摆开 | 排列、同款多件 |
| 真实使用 | 生活场景、非摆拍 | 手持、自然光、生活感 |

## 写提示词时的固定结构

```
[产品] 主体 + 材质 + 颜色
[动作] 谁 + 从哪发力 + 路径 + 终点 + 用时
[镜头] 景别 + 角度 + 运镜（有动机）
[光] 自然光/侧逆光/柔光
[质感] 微距/浅景深/高光细节
[负面] 变形、多余手指、塑料感、文字水印
```

## 常见错误

1. 一个镜头塞三个卖点 → 观众一个都没记住
2. 只拍产品不拍人 → 没有信任感
3. 卖点靠字幕说 → 要"演"出来，字幕只是强调
4. 产品变形不检查 → 服装类必须用真实产品图做参考资产
