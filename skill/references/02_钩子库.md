# 02 · 钩子库

> 前 3–6 秒决定留存。钩子必须与产品相关，且能被画面证明。
> 每条钩子 = 一句台词 + 一个前 3 秒画面。只用一句话，超过 15 字就砍。

## 三种钩子类型

| 类型 | 逻辑 | 适用 |
|---|---|---|
| 痛点型 | 说出观众正在经历的麻烦 | 功能型产品、家居、清洁 |
| 结果型 | 先给结果/对比 | 美妆、健身、收纳、服饰 |
| 反常识型 | 打破预期 | 新品类、贵价品、争议品 |

## 服装

- 痛点：「梨形身材别再买直筒裤了」
- 痛点：「衣柜里那件白衬衫，问题不在颜色」
- 结果：「同一件衣服，换条腰带差 10 斤」
- 结果：「155 穿出 165 的比例，就靠这一条」
- 反常识：「贵的衣服反而更耐穿？我拆了一件」
- 反常识：「显瘦的关键不是黑色」

## 家居 / 收纳

- 痛点：「厨房台面永远乱，是因为少了这一步」
- 痛点：「小户型最浪费的地方，是门后」
- 结果：「3 分钟，把衣柜多出一层」
- 结果：「这个挂钩承重 20 斤，我挂了一桶水」
- 反常识：「收纳盒买错，越收越乱」

## 美妆 / 护肤

- 痛点：「卡粉不是粉底的问题」
- 结果：「同一张脸，左边 3 分钟，右边 30 分钟」
- 结果：「鼻翼的黑头，被这一支吸出来了」
- 反常识：「贵妇霜不如这瓶 30 块的」
- 反常识：「化妆前别洗脸」（需谨慎，勿误导）

## 食品 / 饮品

- 痛点：「减脂期最难的，是晚上那口馋」
- 结果：「一包 3 分钟，比外卖香」
- 反常识：「0 糖不等于没味道」

## 数码 / 小家电

- 痛点：「充电线永远找不到」
- 结果：「插上 5 分钟，用一整天」
- 反常识：「越贵的吸尘器，越不适合小户型」

## 钩子写法公式

```
[痛点] 你不是____，是____
[结果] 只要____，就能____
[反常识] 别再____了，真正该____
[数字] ____天/____元/____秒，做到____
[对比] 左边____，右边____，差的是____
```

## 校验

- 前 3 秒画面里有没有产品/使用/结果？没有就重写
- 钩子能不能被这一条视频证明？不能就删
- 有没有夸大/绝对化？有就换词
