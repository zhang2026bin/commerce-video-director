# 带货导演 · 硬规则

## 一、合规（一票否决）

1. **禁绝对化**：最、第一、顶级、极致、唯一、国家级、王牌、100%、永久
2. **禁保证性**：保证、承诺、彻底解决、根治
3. **禁医疗**：治疗、治愈、疗效、消炎、杀菌（无资质时）
4. **禁虚假对比**：全网最低、指名道姓贬低同行
5. **AI 标识**：AI 生成画面、数字人口播必须在文案或画面标注
6. **披露**：带佣金/合作内容必须写 #ad / #tiktokshop 或口头说明

## 二、真实性

1. 测评必须基于真实使用；模型不得替用户"编体验"
2. 前后对比必须真实、可复现、同光线同角度
3. 数据（销量、复购、时长）必须来自用户提供，不得虚构
4. 效果只写可验证的物理属性（吸水、承重、尺寸），不写主观夸张

## 三、结构

1. 单条 ≤15 秒、≤6 镜（投流版）；长版按 15 秒段落拆
2. 每镜一个说服任务，写在分镜"任务"列
3. 首镜必须出现产品或产品结果
4. 末镜必须有 CTA，且口播 + 屏幕文字双通道

## 四、交付纪律

1. 每次交付固定六件：钩子 3 版、分镜、提示词、投流切片、封面文案、合规检查
2. 交付前必须跑 `commerce_check.py` 且通过
3. 产品图缺失时**先要图**，不用纯文生图硬做（会变形）
4. 不确定的数据标注"待确认"，不编

## 五、隐私

1. 客户产品图、后台截图不外传、不上传第三方
2. 数据截图需打码（店铺名、订单号、个人信息）
