# 01 · 带货方法论（2026-10）

## 一、平台口径（2026）

TikTok Shop Academy 2026-05-20 发布内容指南：

- 三段式：Hook（3–6 秒，必须与产品相关）→ Key Message（利益点）→ CTA（口播+文字）
- 四形态：个人测评、前后对比、开箱、教程/DIY
- FTC 披露义务 + 品牌内容政策；AI 内容需标识
- 商业权重：德国市场头部卖家 60–70% 收入来自 shoppable video + 直播

> 来源：ppc.land 对 TikTok Shop Academy 指南的报道，2026-06-08。

## 二、指标口径

| 指标 | 定义 | 参考线（仅供参考） |
|---|---|---|
| 3s 留存 | 观看 ≥3 秒人数 / 曝光 | ≥50% 算合格 |
| 完播率 | 看完人数 / 播放 | 15 秒素材 ≥25% |
| CTR | 点击购物车 / 播放 | ≥3% |
| CVR | 成交 / 点击 | 品类差异大，1–5% |
| CPA | 花费 / 成交 | 需低于毛利 |

**判断逻辑**：3s 留存低 = 钩子问题；CTR 低 = 卖点不清；CVR 低 = 详情页/价格/信任问题。**别用内容去修 CVR 的问题。**

## 三、素材赛马

- 一个品同时投 3–5 条不同钩子的素材
- 24–48 小时看数据，留强汰弱
- 衰减后换钩子重拍，不换产品

## 四、常见失败模式

1. 钩子与产品无关（纯情绪开场）→ 留存高但转化低
2. 一条视频塞 5 个卖点 → 一个都没记住
3. 卖点全靠字幕 → 静音观看时无信息
4. AI 感太强 → 限流 + 不信任
5. 产品变形 → 退货率高
6. 违规词 → 下架/罚款
